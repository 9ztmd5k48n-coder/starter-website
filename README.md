# My First Website

A simple starter website to learn GitHub and Cloudflare Pages deployment.

## What's in here

- `index.html` - Your entire website in one file (HTML + CSS + JavaScript)

## How to deploy

1. Push this repo to GitHub
2. Connect it to Cloudflare Pages
3. Your site goes live automatically

## Next steps

- Edit the text in `index.html` to make it your own
- Change the colors in the `<style>` section
- Add more pages
- Have fun experimenting!
